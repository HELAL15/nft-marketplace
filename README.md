# NFT Marketplace

## Overview

NFT Marketplace is a modern platform that allows users to discover, buy, and sell digital art as NFTs. The platform provides a seamless and secure experience for creators and collectors, enabling transactions through blockchain technology.

## Features

- Explore a wide range of digital art and NFTs
- Secure and decentralized transactions
- User-friendly interface for buying and selling NFTs
<!-- - Wallet integration for seamless transactions -->
- Responsive design for optimal experience on all devices

## Technologies Used

- **Next.js** – Server-side rendering and static site generation
- **React** – Component-based UI development
- **Tailwind CSS** – Modern styling and responsive design
- **TypeScript** – Ensuring type safety and better development experience

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/nft-marketplace.git
   ```
2. Navigate to the project directory:
   ```bash
   cd nft-marketplace
   ```
3. Install dependencies:
   ```bash
   npm install  # or yarn install
   ```
4. Run the development server:
   ```bash
   npm run dev  # or yarn dev
   ```
5. Open your browser and visit `http://localhost:3000`.
